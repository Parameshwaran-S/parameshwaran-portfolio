# Parameshwaran Portfolio Website

This is a modern portfolio website built with React and Vite, featuring smooth animations powered by Framer Motion.

## Features
- **Responsive Design**: Looks great on all devices.
- **Dark Mode**: Default dark theme for a premium developer look.
- **Animations**: Subtle entry animations for sections.
- **Sections**:
  - Hero (Introduction)
  - About (Objective, Education, Certifications)
  - Experience (Timeline)
  - Projects (Featured Work)
  - Skills (Tag cloud)
  - Contact

## Getting Started

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Start Development Server**:
    ```bash
    npm run dev
    ```
    Open your browser at `http://localhost:5173`.

3.  **Build for Production**:
    ```bash
    npm run build
    ```
    The output will be in the `dist` folder.

## Technologies Used
- React (Hooks, Components)
- Vite (Build tool)
- Framer Motion (Animations)
- Lucide React (Icons)
- CSS Variables (Theming)
